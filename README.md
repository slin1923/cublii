# Overview

Cubli is a controls project trying to balance a cube on its corner via 3 reaction wheels.  This project was inspired by [ETH Zurich](https://idsc.ethz.ch/research-dandrea/research-projects/archive/cubli.html) and [remRC](https://github.com/remrc/Self-Balancing-Cube).  This project is a WIP, please visit my portfolio for details. 

https://slin1923-portfolio.github.io/ 

# Hardware

90% of hardware is courtesy of remRC. however, all his [original Thingiverse files](https://www.thingiverse.com/thing:6695891) are already STLs.  I reverse-designed them to be parametric Onshape files :).  I also desiged some additional parts of my own you can find below. 

For exportable/copyable hardware, please make an Onshape account and use the following links. You will be able to copy and modify the original parametric design files on your own.
